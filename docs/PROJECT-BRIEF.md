# PROJECT BRIEF

PropetraBangladesh is the public-facing business/product website for PROPETRA, a modern cloud-based Property Management System developed and operated by TEAM PETRA.

The website targets hotel owners, hotel managers, resort operators, boutique properties, guest houses and hospitality decision-makers.

Goals:
1. Explain PROPETRA.
2. Demonstrate PMS capabilities.
3. Establish TEAM PETRA credibility.
4. Generate demo/contact requests.
5. Provide a scalable commercial foundation.

This is not the authenticated PMS application and not a hotel booking website.
